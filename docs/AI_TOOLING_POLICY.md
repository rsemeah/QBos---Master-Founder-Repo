# AI Tooling Policy

AI tools (e.g., GitHub Copilot, Copilot Chat) are permitted as advisory aids only.

## Rules

- AI tools may suggest code or wording.
- AI tools may **NOT** assert system status.
- AI tools may **NOT** override canonical documents.
- AI tools may **NOT** synthesize "what QBos is" outside of `QBOS_TODAY.md`.

## Canonical Truth Sources

- [docs/QBOS_TODAY.md](QBOS_TODAY.md)
- `receipts/` and `proof/`
- [docs/TOOL_BOUNDARIES.md](TOOL_BOUNDARIES.md)

If an AI tool contradicts canonical files, **it is wrong by definition**.
